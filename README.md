# מצוות+

אב-טיפוס עובד לאפליקציית מעקב מצוות בסגנון אפליקציית Wellness ישראלית מודרנית. הפרויקט הוסב ל-Vite, React, TypeScript ו-Tailwind CSS להרצה ישירה בדפדפן.

## מה כבר עובד

- דף בית עם יעד יומי, ניקוד, רצף, פעולות מהירות ויומן מצוות
- מסך 100 ברכות עם קטגוריות, ספירה, יומן והשלמת יעד
- מסך דבר תורה עם שמירה, שיתוף, הקראה בקול (Web Speech API), כתיבת מחשבה ורצף לימוד
- מסך שמירת הלשון עם טיימר מתמשך, שיא אישי, התחלה מחדש וטיפים
- מסך התקדמות עם יעדים, גרף שבועי והישגים
- מסך קהילה עם דירוג ואתגר קבוצתי
- מסך פרופיל והגדרות בסיסיות
- הוספת מצווה מהירה מכל מסך
- שמירת המצב בדפדפן באמצעות `localStorage`, כולל היסטוריה מלאה של כל הרישומים
- מסך פתיחה (שם ויעד יומי) ואפשרות לטעון נתוני הדגמה
- ניקוד, דרגות (10 דרגות), רצפים, גרף שבועי, תגים וציון עקביות – מחושבים מההיסטוריה
- ביטול רישום, עריכת יעדים ושמירת הגדרות
- לוח עברי וזמני היום לפי עיר (`@hebcal/core`); בשבת ובחג האפליקציה פעילה ומציגה את מצוות היום, עם רישום בדיעבד למי שלא רשם בזמן
- סידור נוסח ספרד (חול, שבת ומועדים) ותהילים מלא – offline, מספריא
- "המצוות של היום" לפי התאריך העברי, המגדר והזמנים
- תפילות וזמנים, "מה מברכים?", לימוד יומי (7 מסלולים), תרי״ג מצוות, חגים ומועדים
- מנוע ניקוד מבוסס תצורה (`src/data/actions.ts`) עם בונוסים ומגבלות יומיות

## הרצה

```bash
npm install
npm run dev
```

האפליקציה עולה על פורט `3000` (`http://0.0.0.0:3000`).

## בדיקת טיפוסים, בדיקות ובנייה

```bash
npm run lint
npm test
npm run build
```

## מבנה מרכזי

- `src/App.tsx` - ניווט ומעטפת האפליקציה
- `src/store/AppStore.tsx` - Provider ושמירה מקומית ב-`localStorage`
- `src/store/state.ts` - מודל הנתונים, הסבה מגרסה 1, נתוני הדגמה ו-reducer
- `src/store/derived.ts` - כל הערכים המחושבים (היום, שבוע, רצפים, דרגה, תגים)
- `src/lib` - תאריכים, רצפים, דרגות, לוח עברי וזמנים, ניקוד, תוכנית היום ולימוד יומי (פונקציות טהורות עם בדיקות ב-`src/__tests__`)
- `src/data` - תוכן: פעולות וניקוד, ברכות ומאכלים, מצוות, מדריכי חגים, ערים ונוסחים
- `src/screens` - כל מסכי המוצר
- `src/components` - רכיבי ממשק משותפים
- `design-reference` - מסכי העיצוב שעל פיהם נבנה האב-טיפוס

## הערות מוצר

זהו אב-טיפוס מקומי. אין עדיין שרת, חשבונות משתמש, סנכרון בין מכשירים, אימות חברים או מערכת הטבות אמיתית. לפני פרסום בחנויות נדרש לחבר Backend, מדיניות פרטיות, אנליטיקה, בדיקות נגישות, בדיקות מכשירים ומנגנון ניהול תוכן תורני.
