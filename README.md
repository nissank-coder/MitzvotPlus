# מצוות+

אב-טיפוס עובד לאפליקציית מעקב מצוות בסגנון אפליקציית Wellness ישראלית מודרנית. הפרויקט נבנה ב-Expo ו-React Native ומתאים להפעלה ב-iOS, Android והדפדפן.

## מה כבר עובד

- דף בית עם יעד יומי, ניקוד, רצף, פעולות מהירות ויומן מצוות
- מסך 100 ברכות עם קטגוריות, ספירה, יומן והשלמת יעד
- מסך דבר תורה עם שמירה, שיתוף, הקראה בקול, כתיבת מחשבה ורצף לימוד
- מסך שמירת הלשון עם טיימר מתמשך, שיא אישי, התחלה מחדש וטיפים
- מסך התקדמות עם יעדים, גרף שבועי והישגים
- מסך קהילה עם דירוג ואתגר קבוצתי
- מסך פרופיל והגדרות בסיסיות
- הוספת מצווה מהירה מכל מסך
- שמירת המצב במכשיר באמצעות AsyncStorage

## הרצה

דרישות: Node.js 22.13 ומעלה, ו-Expo Go התואם ל-SDK 58.

```bash
npm install
npx expo start
```

לאחר הפעלת השרת:

- סרקו את קוד ה-QR באמצעות Expo Go במכשיר
- לחצו `a` לפתיחה ב-Android Emulator
- לחצו `i` לפתיחה ב-iOS Simulator במחשב Mac
- לחצו `w` לפתיחה בדפדפן

## בדיקת טיפוסים

```bash
npm run typecheck
```

## מבנה מרכזי

- `App.tsx` - ניווט ומעטפת האפליקציה
- `src/store/AppStore.tsx` - מצב האפליקציה ושמירה מקומית
- `src/screens` - כל מסכי המוצר
- `src/components` - רכיבי ממשק משותפים
- `design-reference` - מסכי העיצוב שעל פיהם נבנה האב-טיפוס

## הערות מוצר

זהו אב-טיפוס מקומי. אין עדיין שרת, חשבונות משתמש, סנכרון בין מכשירים, אימות חברים או מערכת הטבות אמיתית. לפני פרסום בחנויות נדרש לחבר Backend, מדיניות פרטיות, אנליטיקה, בדיקות נגישות, בדיקות מכשירים ומנגנון ניהול תוכן תורני.
