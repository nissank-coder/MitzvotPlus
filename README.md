# מצוות+

אב-טיפוס עובד לאפליקציית מעקב מצוות בסגנון אפליקציית Wellness ישראלית מודרנית. הפרויקט הוסב ל-Vite, React, TypeScript ו-Tailwind CSS להרצה ישירה בדפדפן.

## מה כבר עובד

- דף בית עם יעד יומי, ניקוד, רצף, פעולות מהירות ויומן מצוות
- מסך 100 ברכות עם קטגוריות, ספירה, יומן והשלמת יעד
- מסך דבר תורה עם שמירה, שיתוף, הקראה בקול (Web Speech API), כתיבת מחשבה ורצף לימוד
- מסך שמירת הלשון עם טיימר מתמשך, שיא אישי, התחלה מחדש וטיפים
- מסך התקדמות עם יעדים, גרף שבועי והישגים
- מסך קהילה עם דירוג ואתגר קבוצתי
- מסך פרופיל והגדרות בסיסיות
- הוספת מצווה מהירה מכל מסך
- שמירת המצב בדפדפן באמצעות `localStorage`

## הרצה

```bash
npm install
npm run dev
```

האפליקציה עולה על פורט `3000` (`http://0.0.0.0:3000`).

## בדיקת טיפוסים ובנייה

```bash
npm run lint
npm run build
```

## מבנה מרכזי

- `src/App.tsx` - ניווט ומעטפת האפליקציה
- `src/store/AppStore.tsx` - מצב האפליקציה ושמירה מקומית ב-`localStorage`
- `src/screens` - כל מסכי המוצר
- `src/components` - רכיבי ממשק משותפים
- `design-reference` - מסכי העיצוב שעל פיהם נבנה האב-טיפוס

## הערות מוצר

זהו אב-טיפוס מקומי. אין עדיין שרת, חשבונות משתמש, סנכרון בין מכשירים, אימות חברים או מערכת הטבות אמיתית. לפני פרסום בחנויות נדרש לחבר Backend, מדיניות פרטיות, אנליטיקה, בדיקות נגישות, בדיקות מכשירים ומנגנון ניהול תוכן תורני.
