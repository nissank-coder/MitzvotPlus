# סגירת G1 – בדיקות על מכשירים אמיתיים

**חשוב:** סימולטור ואמולטור מקצרים את הדרך, אבל **אינם מחליפים** את המכשירים. G1 נסגר רק עם ראיות מ-iPhone פיזי ומ-Android פיזי. כל תוצאה נרשמת ב-[`test_evidence.csv`](test_evidence.csv): PASS, FAIL, BLOCKED או NOT_RUN, עם מכשיר, גרסת מערכת, commit וקובץ ראיה.

## 0. הכנה (פעם אחת, על ה-Mac)

1. Xcode מה-App Store, ופתיחה אחת שלו.
2. Android Studio, ובו SDK Platform 36 ו-Build-Tools 36.
3. Node 22 ומעלה.
4. במכשיר Android: הגדרות ← אודות ← ללחוץ 7 פעמים על "מספר Build", ואז "אפשרויות מפתח" ← "ניפוי באגים ב-USB".
5. ב-iPhone (iOS 16 ומעלה): הגדרות ← פרטיות ואבטחה ← "מצב מפתח" (Developer Mode).

```bash
git clone https://github.com/nissank-coder/MitzvotPlus.git
```

```bash
cd MitzvotPlus && git checkout claude/fervent-mccarthy-s8uroc && npm ci && npm run verify
```

לרשום את ה-commit שנבדק:

```bash
git rev-parse --short HEAD
```

## 1. הרצה על כל יעד

| יעד | פקודה | בממשק |
|---|---|---|
| iPhone פיזי | `npm run ios:open` | Xcode ← target `App` ← Signing & Capabilities ← Team (Apple ID אישי מספיק) ← לבחור את ה-iPhone ← ▶ |
| סימולטור iOS | `npm run ios:open` | לבחור iPhone SE (מסך קטן) וגם iPhone 16 ← ▶ |

| אמולטור Android | `npm run android:open` | Device Manager ← Pixel עם Android 15/16 ← ▶ |
| אמולטור 16 KB | `npm run android:open` | Device Manager ← system image עם "16 KB page size" (Android 15+) ← ▶ |

## 2. הבדיקות

## 3. איסוף לוגים בעת כשל

```bash
adb logcat -d | grep -iE "capacitor|chromium|sqlite" > android-log.txt
```

ב-iOS: Xcode ← Window ← Devices and Simulators ← המכשיר ← Open Console.

## 4. מתי G1 סגור

כש-T03, T05, T06, T07 ו-T04 מסומנים PASS על **iPhone פיזי ו-Android פיזי**, עם ראיות בתיקייה. כל כשל נרשם FAIL עם תיאור, ולא נמחק.
