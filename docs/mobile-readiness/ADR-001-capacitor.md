# ADR-001: עטיפת הקוד הקיים ב-Capacitor

- **סטטוס:** מוצע (החלטה טכנית; ממתין לאישור בעל המוצר)
- **תאריך:** 2026-11-23

## הקשר

הקוד הוא React DOM + Vite (ראו G0 §2), עם 16 קובצי מסך, לוגיקה טהורה עם 44 בדיקות (כולל 6 בדיקות אחסון וקישורים), ותמיכה מלאה ב-RTL. נדרשת אפליקציה לאייפון ולאנדרואיד.

## החלטה

שומרים את הממשק הקיים ועוטפים אותו ב-**Capacitor 8.6.2**. נתוני המשתמש עוברים ל-**SQLite** (`@capacitor-community/sqlite`) עם migrations. בדפדפן נשאר localStorage לפיתוח.

## נימוקים מהקוד

- אין בקוד תלות ב-DOM שאינה נתמכת ב-WebView, למעט `speechSynthesis` ו-`navigator.share` (רשומים ב-backlog).
- הלוגיקה (ניקוד, לוח, רצפים) נכתבה כפונקציות טהורות ועוברת כמו שהיא.
- ה-APK נבנה בהצלחה ב-Android, בלי שינוי בקוד המסכים (G1).
- מעבר ל-React Native היה מחייב כתיבה מחדש של כל 16 המסכים, בלי צורך שעולה מהקוד.

## השלכות ונקודת בדיקה

- ביצועים ב-Android זול טרם נמדדו במכשיר (BLOCKED). אם הגלילה או הפתיחה איטיות במכשיר ביניים, נבחן מחדש.
- ההחלטה אינה פותרת את ממצא ה-GPL (license-inventory).
