# בדיקה על הטלפון שלך – מדריך קצר

המטרה: להתקין את האפליקציה על Android ועל iPhone אמיתיים, לבצע 8 בדיקות, ולשלוח תוצאות. הגרסה המלאה עם כל המקרים: [device-test-runbook.md](device-test-runbook.md).

## Android – הדרך הפשוטה ביותר (בלי מחשב Mac)

כל ריצת CI מייצרת קובץ התקנה (APK) ושומרת אותו 14 יום.

1. בטלפון או במחשב, מחוברים ל-GitHub: **Actions** ← הריצה האחרונה של **CI** שהצליחה ← בתחתית הדף, **Artifacts** ← `android-debug-apk`.
2. יורד קובץ ZIP. לפתוח אותו (בטלפון: אפליקציית "קבצים" ← לחיצה על ה-ZIP ← "חילוץ"), ובפנים נמצא `app-debug.apk`.
   - אם הורדת במחשב: לשלוח את ה-APK לעצמך (מייל, Google Drive או WhatsApp), ולפתוח אותו בטלפון.
3. ללחוץ על הקובץ. Android יבקש לאשר "התקנה ממקור לא ידוע" לאפליקציה שממנה פתחת – לאשר, ולהתקין.
4. זו גרסת debug, שנועדה לבדיקה בלבד. Play Protect עשוי להציג אזהרה; אפשר לבחור "התקן בכל זאת".

## iPhone – דרך ה-Mac (אין דרך להתקין קובץ ישירות בלי חשבון מפתחים)

1. לחבר את ה-iPhone ל-Mac בכבל. ב-iPhone: הגדרות ← פרטיות ואבטחה ← **מצב מפתח** ← להפעיל (הטלפון יופעל מחדש).
2. ב-Mac, בטרמינל:

```bash
git clone https://github.com/nissank-coder/MitzvotPlus.git
```

```bash
cd MitzvotPlus && npm ci && npm run ios:open
```

3. ב-Xcode: בצד שמאל `App` ← לשונית **Signing & Capabilities** ← **Team**: להוסיף את ה-Apple ID שלך. בסרגל העליון לבחור את ה-iPhone, וללחוץ ▶.
4. בפעם הראשונה, ב-iPhone: הגדרות ← כללי ← VPN וניהול מכשירים ← לאשר את המפתח (ה-Apple ID שלך).
5. התקנה כזו פגה אחרי 7 ימים. כדי לשלוח לאחרים בלי כבל צריך חשבון Apple Developer (99$ לשנה) ו-TestFlight. זה הצעד הבא, אחרי שהבדיקות האלה עוברות.

## 8 בדיקות (כ-15 דקות לכל טלפון)

| # | מה עושים | מה צריך לקרות |
|---|---|---|
| 1 | פותחים, נרשמים, עוברים בין כל הלשוניות | אין מסך לבן; הכל בעברית מימין לשמאל |
| 2 | מוסיפים 3 ברכות ומסמנים שחרית | הנקודות בראש המסך עולות |
| 3 | סוגרים את האפליקציה בכוח (החלקה מרשימת האפליקציות) ופותחים שוב | הברכות, השחרית והנקודות נשארו |
| 4 | מצב טיסה, ואז סידור ותהילים | הטקסטים נפתחים |
| 5 | שמירת הלשון: מפעילים, מאפסים, "ביטול האיפוס", סוגרים בכוח ופותחים | הטיימר ממשיך מאותה נקודה |
| 6 | באנדרואיד: כפתור/מחוות "חזרה" ממסך פנימי. באייפון: החלקה מהקצה | חוזר מסך אחד אחורה |
| 7 | הכותרת וסרגל הניווט התחתון | לא מוסתרים בגלל המצלמה (notch) או סרגל המערכת |
| 8 | מגדילים את גופן המערכת לגודל המרבי, ופותחים את 100 ברכות | אין טקסט חתוך או כפתורים שנעלמו |
