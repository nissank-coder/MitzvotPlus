# שערי שחרור ומטריצת בדיקות

תאריך הכנת המסמך: 23.11.2026. גרסה: 1.0.

**זהו מפרט לביצוע בדיקות. אף שורה במסמך אינה מעידה שהבדיקה בוצעה או שהאפליקציה מוכנה לחנות.** הגרסה המדויקת של הקוד, הבנייה והסביבה תתווסף בעת הביצוע. מקורות S## מופיעים ב־07_SOURCES.md. החלטות שטרם הוכרעו מופיעות ב־06_DECISIONS_HE.md.

## 1. איך משתמשים במסמך

לכל הרצה מתעדים: תאריך UTC, אחראי, commit SHA, branch, מזהה build, סביבת backend, מכשיר ומערכת הפעלה, גרסאות WebView או iOS, מצב רשת, מדיניות זמן ונתוני בדיקה. קישור ראיה יכול להפנות ללוג מסונן, צילום מסך, סרטון, דוח CI, תוצאת שאילתת בדיקה או רשומה בקונסולת החנות. אין לצרף סודות או פרטים של משתמשים אמיתיים.

| סטטוס | משמעות |
| --- | --- |
| NOT_RUN | הבדיקה טרם הורצה על גרסה מזוהה |
| PASS | התוצאה הצפויה התקבלה ונשמרה ראיה |
| FAIL | לפחות תנאי קבלה אחד נכשל; מצורף מזהה תקלה |
| BLOCKED | אי אפשר להריץ בגלל תלות, הרשאה, החלטה או תשתית חסרה; מתועדת סיבת החסימה |

אין לסמן PASS על סמך קריאת קוד, צילום עיצוב, build של דפדפן או הבטחה של ספק. כאשר תכונה נדחית מהגרסה, מציינים החלטת היקף וקובעים שהבדיקות שלה אינן חלק מהשחרור; לא הופכים אותן לבדיקות שעברו. בדיקה על גרסה ישנה מחייבת בחינת השפעת השינויים לפני קידום גרסה חדשה.
