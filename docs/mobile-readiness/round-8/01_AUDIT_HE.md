## תקציר והחלטה

להמשיך עם React 19 + TypeScript + Vite + Capacitor 8.6.2. PR A נמצא ב-main שסופק, וכן שני השיפורים שדווחו בסבב הקודם: CI לסימולטור iOS ותהליך אישור דברי תורה. אין לפתח אותם מחדש. כעת שני מסלולים במקביל: אמינות מדידה + בניית לולאת המשחק המקומית, והמשך G1/פרטיות/רישוי. המשחקיות החברתית היא יעד לגרסה הציבורית הראשונה; אלפא מקומית אינה ההשקה הציבורית.
