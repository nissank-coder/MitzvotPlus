- `02_PRODUCT_SPRINT_HE.md` - PRs, מודל הרגלים ואתגרים, 12 הצעות אתגר, 16 הישגים, UX, תוכן, קהילה ודרישות טכנולוגיות.
- `03_ACCEPTANCE_HE.md` - מטריצת בדיקות קבלה ומסגרת דוח ביצוע.
- `04_CLAUDE_PROMPT_HE.md` - ההוראה המוכנה לביצוע PR A+ והצגת סקיצות; אין לבצע את כל הסבבים בבת אחת.
