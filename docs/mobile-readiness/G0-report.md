## 7. חבילת תוכן 1 (סבב 4) – הערות לבודק התוכן

- הטקסטים נלקחו כלשונם מספריא, בלי עריכה. השמטת HTML בלבד; הוראות (`<small>`) מוצגות בכתב קטן.
- **שמות קודש:** נוסח הסידור מכיל את השם המפורש בניקוד, כמו בסידור מודפס. הצגה במסך ושמירה במכשיר – לבירור עם הרב המלווה.
- הסידור מציג נוסח מלא. קטעים שנאמרים רק בימים מסוימים (עשי"ת, ר"ח, תחנון) מסומנים כפי שהם במקור. "סידור חכם" שמסנן לפי היום – עדיין לא.
- לרוב קטעי ימות החול אין מהדורת Public Domain בספריא, ולכן נלקחה מהדורת Metsudah 1981 ברישיון CC-BY, עם ייחוס בתחתית כל קטע.
