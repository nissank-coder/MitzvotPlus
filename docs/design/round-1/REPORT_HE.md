## 3. באגים שנמצאו ותוקנו

1. **"תפילה" בכל התפילות.** בחלון ההוספה, שם הקטגוריה דרס את שם הפעולה. לכן חמישה אריחים נקראו "תפילה" (שחרית, מנחה, ערבית, תפילין, תהילים) ושניים נקראו "ברכות". **עכשיו:** כל אריח מציג את שם הפעולה. **בדיקות:** בדיקת יחידה ובדיקת קצה.
2. **הקשה כפולה.** בחלון ההוספה, ההקשה השנייה נפלה על מה שמתחת לחלון. בבדיקה היא פתחה את החלון שוב, ובשימוש אמיתי הייתה עלולה ללחוץ על "רשמתי" ולרשום פעולה נוספת. **עכשיו:** החלון נשאר כ-350ms עם סימון "נרשם ✓" ובולע את ההקשה השנייה. **בדיקה:** בדיקת קצה.
3. **שעון "מוקדם" מיד אחרי איפוס.** בשמירת הלשון הופיעה לשנייה אזהרה שגויה ש"שעון המכשיר מוקדם". **עכשיו:** יש סובלנות של 5 שניות, והמסך מתרענן מיד. **בדיקה:** בדיקת יחידה.
4. **חזרה מהרקע.** הטיימר מתעדכן מיד כשהאפליקציה חוזרת מהרקע. הזמן תמיד מחושב מחותמת הזמן השמורה. **בדיקה:** בדיקת יחידה.

## 4. שינויים שמשפיעים על התנהגות (לאישורך)

1. **מניין:** תיבת הסימון הכללית "תפילה במניין" בחלון ההוספה הוחלפה בשאלה לכל תפילה: במניין או ביחידות. הניקוד לא השתנה.
2. **ההודעה אחרי רישום:** מוצגת 4 שניות במקום 2.6, וכוללת "ביטול".
3. **מסך הבית:**
   - שורת הרישום המהיר (צ'יפים) הוסרה. רישום מהיר של ברכה נמצא בשורת הברכות, וכל השאר דרך כפתור ההוספה.
   - אריח "ההתקדמות שלי" הוסר. ההתקדמות נגישה מהשבוע ומהניווט.
   - שורת ארבעת המספרים (רישומים, פעולות, ברכות, נקודות) הוחלפה בשורה משנית אחת מתחת לרשימת היום.
4. **ברכות:** חלון "השלמת את היעד" הפך להודעה בתוך המסך, שלא עוצרת את המשתמש. הרשימה מציגה 12 רישומים, ו"ועוד N".
5. **דבר תורה:** הוסרו שני אריחים שלא עשו דבר ("שיעור קצר" ו"מחשבה נוספת"), ונוספה אפשרות לבטל את רישום הלימוד.
6. **שמירת הלשון:**
   - טבעת "האתגר השבועי" הוסרה, כדי שלא להפוך את הטיימר הפרטי לאתגר.
   - כפתור האיפוס כבר לא אדום.
7. **לא שונה, ודורש החלטה:** הרגלי "20 ברכות" ו"50 ברכות" חופפים ליעד הברכות היומי (100). הכל נשאר כמו שהיה; ההכרעה היא החלטת מוצר.

**נשמרו:** כללי הניקוד, היעדים, גבול היום, שבת וחג, הפרטיות, הסנכרון והשמירה. לא נוסף תוכן תורה, ולא הוצגה חברתיות כאילו היא קיימת.

## 7. הוראות הרצה

**שרת פיתוח** (עם תוכן הדגמה מסומן):
```bash
npm run dev
```

**בנייה פנימית מקומית:**
```bash
VITE_DEMO_CONTENT=true npx vite build --outDir dist-design && npx vite preview --outDir dist-design
```

**צילומי הסבב ובדיקות הפריסה:**
```bash
node scripts/design/shots.mjs
```

**בדיקות קצה על בניית הייצור:**
```bash
npm run e2e
```

**APK פנימי:** נבנה ב-CI. הקישור בסעיף 8, ובתוך הקובץ יש `build-identity.json`.

## 9. לסבב הבא

1. **הרחבת השפה החזותית:**
   - התקדמות מלאה, עם גרף שבועי ומעבר בין תקופות;
   - מסלולים, אתגר פעיל ויעד קבוצתי;
   - ספרייה, פרופיל והגדרות (פרטי גרסה למקטע משני);
   - תהילים, סידור, זמנים ומועדים.
2. **הישגים:** הבחנה בין הישגים, וההישג הקרוב קודם לכל המאגר.
3. **בדיקה בטלפון:**
   - קורא מסך (TalkBack או VoiceOver);
   - גודל טקסט של המערכת;
   - safe areas ומקלדת;
   - הקראה בעברית;
   - הטיימר אחרי שהאפליקציה בתוך הרקע זמן רב.
4. **החלטות מוצר:** חפיפת יעדי הברכות (20 ו-50 מול 100), ואישור השינויים שבסעיף 4.
